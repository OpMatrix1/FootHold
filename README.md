# FootHold

FootHold is a TypeScript opportunity platform built with React, Vite, Tailwind CSS, and Supabase. The project is designed around a practical job marketplace workflow where users can post listings, browse roles, manage applications, upload CVs, and coordinate interview outcomes.

This repository also includes a polished portfolio-style frontend that presents FootHold alongside related software projects, developer experience, and contact links.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Framer Motion

## Getting Started

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Supabase

Supabase schema and seed files are included in the `supabase/` directory. Authentication redirect setup notes are available in `SUPABASE_AUTH_SETUP.md`.
